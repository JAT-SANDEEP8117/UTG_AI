# 🎓 UTG_AI — University Timetable Generator (AI-Powered)

An intelligent, constraint-aware university timetable scheduling system powered by AI algorithms. Designed to automate and optimize the complex task of generating conflict-free academic schedules for universities.

---

## 🚀 Features

- ⚡ AI-driven timetable generation using constraint satisfaction
- 📊 Space utilization analytics and reporting
- 🧩 Custom solver configuration and draft management
- 🖥️ Interactive dashboard for admins and staff
- 🔄 Real-time generation status tracking
- 📅 Support for multi-department, multi-room scheduling

---

## 🛠️ Tech Stack

| Layer      | Technology              |
|------------|------------------------|
| Frontend   | React.js               |
| Backend    | Node.js / Express.js   |
| Database   | MongoDB                |
| AI Solver  | Custom Constraint Engine|

---

## 📦 Getting Started

### Prerequisites
- Node.js >= 18.x
- MongoDB (local or Atlas)

### Installation

```bash
# Clone the repository
git clone https://github.com/JAT-SANDEEP8117/UTG_AI.git
cd UTG_AI

# Install backend dependencies
cd server && npm install

# Install frontend dependencies
cd ../client && npm install
```

### Running the App

```bash
# Start backend
cd server && npm run dev

# Start frontend (in a new terminal)
cd client && npm run dev
```
